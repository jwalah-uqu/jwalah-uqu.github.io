# منصة نادي الجوالة — جامعة أم القرى

#الكشفية_درب_تعلم_لاينتهي

## الملفات
| الملف | وظيفته |
|---|---|
| `index.html` | كل صفحات المنصة: الرئيسية، من نحن، القادة، اللجان، التسجيل، حسابي، الإدارة |
| `style.css` | التصميم بألوان دليل هوية جامعة أم القرى |
| `app.js` | منطق المنصة (اللجان والأدوار في أول الملف وتقدر تعدّلها) |
| `firebase-config.js` | إعدادات Firebase — فاضي = وضع تجريبي |
| `firestore.rules` | قواعد الحماية |
| `assets/` | الصور والشعارات |

## التشغيل الحقيقي (نفس خطوات منصة النادي الرياضي)
1. أنشئ مشروع Firebase جديد للجوالة، وفعّل **Authentication ← Email/Password** و **Firestore**.
2. أضف Web App وانسخ الـ config في `firebase-config.js`.
3. الصق محتوى `firestore.rules` في **Firestore ← Rules** واضغط Publish.
4. في **Authentication ← Settings ← Authorized domains** أضف دومين GitHub Pages.
5. **أول رئيس للنادي:** سجّل من المنصة بأي دور، ثم من Firestore افتح `users/{uid}` وعدّل:
   `role = "president"` و `approved = true` و `public = true`. بعدها هو يعتمد الباقين من لوحة الإدارة.
6. ارفع الملفات على مستودع GitHub وفعّل Pages.

## الهيكل والنقاط
- **الرئاسة:** رئيس واحد + ٣ نواب.
- **كل لجنة:** قائدان ونائبان للطلاب، ومثلهم للطالبات. لوحة الإدارة ترفض الاعتماد إذا اكتمل العدد.
- **اللجان:** لجنة الموارد البشرية، لجنة جودة الحياة، لجنة المسابقات والأنشطة، لجنة العلاقات العامة، قسم الإعلام والتصميم (تُعدَّل من أول `app.js`).
- **النقاط:** الرئيس ونوابه يسجّلونها من لوحة الإدارة (لجنة + عدد + سبب)، وصفحة اللجان ترتّبها وتعطي الأولى شارة «الأولى».
- **الفعاليات:** القادة يضيفونها، والأعضاء يسجّلون حضورهم.

## الصلاحيات
- **عضو:** يُعتمد تلقائيًا، يشوف لجنته وإعلاناتها.
- **قائد / نائب قائد / نائب رئيس:** يحتاج اعتماد الرئاسة، بعدها يظهر في صفحة القادة، وينشر إعلانات وتغريدات، ويشوف كل اللجان.
- **الرئيس ونوابه:** لوحة الإدارة (اعتماد، رفض، تغيير الدور واللجنة).
